    How to use the analysis board

    Quick start

    1. Get the board in. Use New game ▾ → Random board to practise, or Open ▾ → Read Colonist screenshot (or drag a screenshot onto the board) for a real game. After a screenshot, the board opens in Edit board mode: click anything that was read wrong.
    2. Set up the players with Players: colours (black, green… too), names and turn order. Then pick yourself in the Me menu so your own hand is tracked exactly.
    3. Setup (snake draft). Click the first player's row, then a corner for their settlement and an edge for their road; the turn order rotates to start with them and the board follows 1→4 then 4→1. The engine rings the best spots, and second settlements collect their starting cards. Prefer free placement? Players → untick "Snake draft".
    4. Play along. Each turn click the number rolled, click the board for whatever was built, and press End turn. Trade and Dev card cover the rest. The engine updates after every move; ▶ play applies a suggestion.
    5. Joining mid-game? Press ✎ next to each player to set their cards and dev cards.
